添加一台 Windows 电脑

三步完成。被控端只发起出站连接，家里路由器和公司防火墙都不用开端口。

1

在 Windows 上安装被控端

约 1 分钟

在目标电脑上以管理员身份打开 PowerShell，粘贴一行命令。安装为 Windows 服务，开机自启，锁屏后照常工作。

PS> irm https://relay.example.com/install.ps1 | iex

已经有 winget 的话也可以：

PS> winget install terminalX.Agent
  • 中转节点地址是你自己的（示例 relay.example.com），不经过任何第三方云。
  • 默认 shell 为 PowerShell 7，可改为 cmd、WSL 或 Git Bash。

第一阶段架构

三个部分：控制端（Web）、自建中转节点、Windows 被控端。终端字节流走端到端加密通道；AI CLI 的状态事件走同一条通道回推到手机。

第一阶段做什么
  • Web 控制台：设备列表、会话标签页、xterm.js 终端、待确认收件箱
  • 自建中转：单二进制部署，设备配对与转发，不落盘会话内容
  • Windows 被控端：Windows 服务，ConPTY 会话常驻，断线重连回放
  • AI 感知：先接 Claude Code hooks 与 Codex notify，其余工具走通用输出规则兜底
  • 安全默认值：出站连接、设备配对密钥、Passkey/TOTP 登录、设备吊销
第一阶段不做什么
  • GUI 画面远程、文件传输、剪贴板同步
  • macOS / Linux 被控端（接口预留，第二阶段）
  • 原生手机 App（先用响应式 Web + 推送）
  • 多人协作与团队权限
  • 自动解析每个 CLI 的 TUI 细节（只做「需要你」这一类事件）
