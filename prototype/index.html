手机端（PWA）

手机不是用来「看远程桌面」的。它做两件事：处理 agent 的请求，以及给它下一句指令。终端是只读视图加键条，整行文字走独立输入框，不往终端里直接打中文。

添加一台 Windows 电脑

三步完成，不需要管理员权限。被控端只发起出站 443 连接，家里路由器和公司防火墙都不用开端口。

1

在 Windows 上安装被控端

约 1 分钟

在目标电脑上打开 PowerShell（普通用户即可），粘贴一行命令。安装为登录自启（任务计划程序），崩溃后 1 分钟内自动拉起。

PS> irm https://relay.example.com/install.ps1 | iex
  • 中转节点地址是你自己的（示例 relay.example.com），不经过任何第三方云。
  • 默认 shell 为 PowerShell 7（没有则用 5.1），cmd 可选；Git Bash / WSL 尽力支持。
  • 电脑睡眠或注销后会离线。向导会建议关闭睡眠，并可选开启自动登录；这一步以后没有变化，Windows 没有让服务替登录用户开终端的官方路径。
  • 安装包会做代码签名，避免被 Defender 拦下；winget 分发在后续版本提供。
2

输入配对码或扫码

5 分钟内有效

安装完成后被控端向导会提示输入这个配对码（也可用 install.ps1 -Code 直接带上）。二维码用于手机扫码登录控制台。然后核对两端显示的同一个指纹短码。

7K4P-9Q2M8 位一次性配对码

剩余 04:41 · 输错 5 次锁定 15 分钟

这里显示A7K3-9QZP
被控端显示A7K3-9QZP
  • 配对码本身就是密钥协商的输入，不经中转明文；二维码只用于手机端登录，不参与被控端配对。
  • 配对时双方交换公钥并各自保存对方指纹。第一阶段流量走 TLS 到自建中转；帧格式已按不透明字节设计，逐帧端到端加密在 1.1 实装，届时校验失败即断、不降级明文。

第一阶段架构与范围

三个部分：控制端（Web / 手机 PWA）、自建中转节点、Windows 被控端。只传字节与事件，不传像素。AI CLI 的状态事件走同一条通道回推到手机。

第一阶段做什么
  • Windows 被控端：单 exe，登录自启，ConPTY 会话常驻，断线补差回放，重启后一键拉回（claude --resume / codex resume）
  • 自建中转：单二进制 + Docker 一条命令，配对码、路由、心跳、设备吊销，只存元数据
  • Web 控制台：收件箱首页 + 全局状态条、设备列表、会话列表、多标签终端、三信号连接状态、远程解卡
  • Claude Code：--settings 注入 http hooks（不改你的 settings.json），默认通知模式，每会话可开远程优先；statusLine 只采费用与上下文两个数
  • Codex：hooks.json / notify 登记 → 收件箱 + 打开终端 + 键条
  • Grok Build：终端 + hooks 尽力（事件名待核实），否则疑似状态
  • MiniMax：供应商预设，让 Claude Code / Codex 走 MiniMax 端点，环境变量在被控端注入
  • 手机 PWA：只读终端 + 键条 + 独立输入框；通用 webhook 通知（飞书 / 企微 / Bark / ntfy）
  • 安全默认值：只出站、回环 hooks、远程默认关闭、显式配对与指纹比对、Passkey / TOTP、吊销、暂停总开关、远程 ≤ 本地
第一阶段不做什么
  • GUI 画面远程、剪贴板同步 永不做；UAC、图形安装器请在本机处理
  • 逐帧端到端加密实装 1.1；任何托管或多人使用前的硬门槛
  • Windows 服务化 长期约束，见左侧说明
  • Codex 一键审批（app-server）1.1 试验
  • 成本面板与额度环、额度耗尽自动续跑 1.1 仅 Claude；续跑对 API Key 无意义
  • 只读分享链接、录制回放、审计页 1.1 / 2 / 3
  • 多机聚合告警与用量、macOS / Linux 被控端 第二阶段
  • 原生 App、Web Push、手机传图到被控端 1.1 / 2
  • ACP 接入其余工具、团队权限与 SSO、跨机器接续 1.2 / 3 / 不承诺
第 1 周先验证三件事
  • ConPTY 起 claude 并在 xterm.js 渲染：固定 ≥100 列，首屏 ≤1 秒，20000 行逐字节一致
  • 原生 Windows 上 http 型 PermissionRequest / Notification hook 真的触发与回写（社区有多个 hooks 在 Windows 不触发的未关闭问题）
  • Android 真机：输入框 50 个中文字符逐字节到达 PTY
已知限制
  • 被控端进程退出则 ConPTY 一起退出；靠 supervisor / ptyhost 双进程和自动拉回缓解
  • 睡眠、注销、未自动登录即离线
  • Claude Code 原生 Windows 无沙箱（仅 WSL2）；--settings 与官方 Remote Control 不能同时使用
  • Claude TUI 在 ConPTY → xterm.js 链路有已知重绘问题；手机端不承诺 40 列
